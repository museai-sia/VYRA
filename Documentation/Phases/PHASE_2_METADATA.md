# PHASE 2 — METADATA（予定のみ・実装禁止）

本ドキュメントは将来フェーズの予定仕様の保存用であり、Phase 1 では実装しない。

## 予定内容

- 公式に許可された情報取得手段と利用規約に適合する範囲で、動画メタデータ（タイトル、投稿者、時間、サムネイル等）の実取得を行う。
- 実装は `VideoMetadataService` プロトコルの実サービス差し替えとして行い、Mock 実装と置換可能に保つ。
- YouTube のアクセス制御やダウンロード制限を回避する手段は採用しない。

## 開始条件

Phase 1 完了と、開発者による Phase 2 開始の明示承認。
